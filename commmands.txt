# Docker CLI Command Cheat Sheet

## 1. Container Lifecycle
* `docker run -d --name <name> -p <host>:<container> <image>` - Run container in background (detached mode) with name and port mapping.
* `docker start <container>` - Start a stopped container.
* `docker stop <container>` - Stop a running container gracefully.
* `docker restart <container>` - Restart a container.
* `docker rm <container>` - Remove a stopped container.
* `docker rm -f <container>` - Force-remove a running container.

## 2. Monitoring & Debugging
* `docker ps` - List all running containers.
* `docker ps -a` - List all containers (running and stopped).
* `docker logs -f <container>` - Stream container logs in real time.
* `docker exec -it <container> bash` - Open an interactive bash shell inside a container.
* `docker inspect <container>` - Return detailed JSON metadata about a container.
* `docker stats` - Display a live stream of container resource usage statistics.

## 3. Image Management
* `docker images` - List all local images.
* `docker build -t <image_name>:<tag> .` - Build an image from a Dockerfile in the current directory.
* `docker pull <image>` - Download an image from Docker Hub registry.
* `docker rmi <image>` - Remove a local image.
* `docker history <image>` - Show the layer history of an image.

## 4. Volumes & Networks
* `docker volume ls` - List all local volumes.
* `docker volume create <name>` - Create a new named storage volume.
* `docker network ls` - List all networks.
* `docker network create <name>` - Create a new container network.

## 5. Maintenance & Cleanup
* `docker system prune` - Delete all stopped containers, unused networks, and dangling images.
* `docker image prune` - Remove dangling images from storage.
* `docker cp <src> <dest>` - Copy files or folders between a container and the local host filesystem.
